# Templates de Issues — NotificaSaúde

Este repositório contém os **templates de issues** utilizados no projeto **NotificaSaúde**.

Os templates foram definidos com base nas práticas de **Engenharia de Software**, com o objetivo de padronizar a criação e organização do backlog no GitHub, garantindo clareza, rastreabilidade e alinhamento com o documento de requisitos do sistema.

## Objetivo

Padronizar a estrutura das issues para:

- Facilitar a comunicação entre os membros da equipe
- Garantir consistência na descrição de requisitos
- Melhorar a rastreabilidade entre épicos, histórias de usuário e tarefas
- Apoiar o processo de desenvolvimento incremental do sistema

## Tipos de Templates

O repositório contempla os seguintes templates:

### Épico
Utilizado para representar grandes blocos de funcionalidade do sistema, alinhados aos objetivos de negócio e aos módulos do produto.

---

### História de Usuário
Utilizado para descrever funcionalidades sob a perspectiva do usuário, seguindo o modelo:

> COMO / QUERO / PARA

Inclui critérios de aceite no formato **DADO / QUANDO / ENTÃO**, alinhados ao documento de requisitos.

---

### Task
Utilizado para descrever atividades técnicas ou operacionais necessárias para implementação das histórias de usuário.

Inclui:
- Contexto
- Problema
- Solução proposta
- Critérios de conclusão

---

## Observação

Os templates devem ser utilizados em conjunto com o **documento de requisitos do NotificaSaúde**, garantindo alinhamento entre especificação e desenvolvimento.
